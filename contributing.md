# Contributing Guidelines

Before contributing, please read the [awesome manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md).

- Search existing entries before adding a new one to avoid duplicates.
- Add one entry per pull request, at the bottom of the appropriate category.
- Use the format: `- [Name](link) - Description.` The description starts with a capital letter and ends with a period.
- Only submit software that is actively maintained, has working install instructions, and is not archived.
- Explain in the pull request why the entry belongs on the list.
